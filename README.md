# zoom-chain — ズーム遷移ギミック

ピンチイン／ピンチアウトで**異なるイラスト間を遷移する**プロトタイプ。
単一HTMLファイル・依存ライブラリなし・Canvas 2D のみ。

▶ **[プレイする](https://toshime.github.io/zoom-chain/)**（スマホ推奨）

## あそびかた

ハエが止まっているところが、次に寄る場所。

1. ハエに向かってピンチアウト（デスクトップはホイール／トラックパッドのピンチ）
2. 寄りきると、背後の生き物がクロスフェードで入れ替わる
3. 引くと「別の生き物になっている」ことに気づく ← これが体験の核
4. ハエが1回だけ飛んで次の場所に止まる。1へ戻る

寄りきったのに引かないでいると、ハエが激しく羽ばたいて催促する。

## 連鎖（1周）

```
カエルの目 →(寄る)→ タコの目 →(ハエ移動)→ タコの吸盤
          →(寄る)→ イカの吸盤 →(ハエ移動)→ イカの別の吸盤
          →(寄る)→ カエルの指の吸盤 →(ハエ移動)→ カエルの目 → ループ
```

## 構成

| ファイル | 中身 |
|---|---|
| `index.html` | ゲーム本体（HTML/CSS/JS 全部入り） |
| `CONTEXT.md` | 設計ドキュメント。座標系・アンカー・クロスフェード・描画の仕組み |

`CONTEXT.md` は**コードを触る前に読むこと**。特に「2. 座標系とアンカー」と
「4. クロスフェード」は、理解せずに書き換えると画面がワープするか絵が濁る。

## ローカルで動かす

`index.html` をブラウザで開くだけ。サーバも不要。

```bash
open index.html
```

## イラストの差し替え

`CONTEXT.md` の「8. 本番イラストへの差し替え手順」を参照。
`drawFrog / drawOcto / drawSquid` を置き換え、`CREATURES[i].anchors` を新しい特徴点に更新する。
連鎖を増やす場合も `CREATURES` と `CHAIN` に足すだけで、他のコードは触らなくてよい。
